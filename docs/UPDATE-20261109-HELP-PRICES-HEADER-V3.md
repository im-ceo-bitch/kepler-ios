# iumrah v3: подсказки, цены, pull-to-refresh

Это накопительный ZIP относительно присланного репозитория. Имя начинается с
`iumrah-beta-update-`, файлы лежат относительно корня и совместимы с имеющимся распаковщиком.
Загрузите архив в корень main. После распаковки запустите существующие сборку iOS
и деплой PackageEngine. Распаковщик делает commit с [skip ci], поэтому распаковка
сама по себе не является сборкой или выкладкой Worker.

## Что изменено

- Одна свёрнутая карточка «Что делать сейчас?» под поиском/сводкой; на страницах
  без поиска — в начале содержимого. Крупный текст, Lato, анимированная рамка,
  поддержка Reduce Motion и системного размера текста.
- Все 54 текста имеют отдельные RU, EN, UZ Latin и UZ Cyrillic строки.
  Выбор текста зависит от контекста; резервные варианты не показываются одновременно.
  Другие языки используют английский текст этой новой функции.
- Подключены пять вкладок, разделы каталога, выбор перелётов, отелей и номера,
  трансфер, итог, контактная форма, календарь и пассажиры. Учтена отдельная
  действующая ветка TripBuilder/PrimaryHotel/LegacyFinalPackage.
- Реальные возвращённые API значения больше не обнуляются по sandbox/pricesStale.
  Sandbox помечается как тестовый тариф; сохранённая цена — как сохранённая.
- Каталог при ожидании показывает загрузку цены. После пустого ответа или ошибки
  предлагает открыть номера, а не заменяет всю витрину на «Уточнить цену».
  Уточнение цены остаётся дополнительным действием внутри отеля после завершения
  запроса. Пока запрос выполняется, эта функция не появляется.
- Убраны собственные 10-секундные параметры hotel-rate запросов и 22-секундный
  AbortSignal для цены на Worker. Для iOS выделена отдельная сессия цен вместо
  ограничений 35/60 секунд. Технические интервалы URLSession выставлены в 7 суток;
  UI не принимает решение об отсутствии цены по таймеру. Бесконечное соединение
  не гарантируется: ограничения Nuitee, сети и платформы продолжают действовать.
- Хедер компенсирует только фактический overscroll из UIScrollView.contentOffset
  с adjustedContentInset; расчёт больше не зависит от GeometryReader/safe-area.
  При прокрутке вверх компенсация равна нулю. Spinner размещён после хедера.
  Поиск/сводка сворачиваются при вытягивании; refresh запускается при отпускании
  после порога и не запускает вторую задачу, пока первая не завершена.
- Высота +20 pt и форма предыдущего патча сохранены: округлый низ только на Главной.

## Проверено

- TypeScript: npm run typecheck — успешно.
- Backend runtime: 39/39, включая отложенный ответ цен без собственного deadline.
- Контракты хедера: 7/7.
- Все изменённые Swift-файлы проверены синтаксическим парсером.
- Полный старый набор контрактов: 140/145; остаются пять существовавших ранее ошибок
  (carousel, generator-production-pricing, widgets locale, legacy booking labels,
  passwordless entry). Они не скрыты и не отключены.
- Все ключи подсказок имеют 4 записи; проверены ссылки на ключи и состав ZIP.

Xcode и iOS SDK здесь отсутствуют. Синтаксический разбор не заменяет компиляцию
и проверку интерфейса. Архив не заявляется проверенным на реальном iPhone.

## Проверка после сборки

1. На каждой основной вкладке и в конфигураторе потянуть вниз: чёрная часть
   остаётся на верхней границе, двигается содержимое, spinner виден ниже.
2. Прокрутить вверх: хедер уходит с содержимым. Проверить светлую/тёмную тему,
   iPhone 11/13 mini, короткий контент и раскрытый поиск.
3. Переключить четыре языка, раскрыть подсказки; проверить крупный шрифт.
4. Проверить цены: медленный ответ, успешный тариф, пустой ответ, ошибка,
   смена дат до ответа и повторное открытие. Поздний ответ старого запроса
   не должен перезаписывать новые параметры.
5. Проверить, что тестовый тариф явно обозначен. Для production-стоимости
   требуется production-ключ Nuitee; этот патч не меняет ключи.

Перевод гостиничных описаний из v2 сохранён: language Nuitee, опционально
HOTEL_TRANSLATION_API_KEY для Google Cloud Translation. Эта настройка не нужна
для четырёх языков новых подсказок: они включены непосредственно в приложение.
