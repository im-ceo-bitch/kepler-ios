# iumrah · Black Identity + Umrah Flow V2 — единый ZIP-патч

Дата: 27.10.2026. Архив предназначен для существующего репозитория kepler-ios и распаковщика `iumrah-beta-update-*.zip`.

## Часть 1: UI Redesign
- Пять основных вкладок: общий чёрный header/safe area, компактный header поверх прокрутки; содержимое не перекрывается tab bar.
- Pull-to-refresh: чёрный верхний фон и белый native UIRefreshControl spinner. Верхнее системное статус-бар оформление — белое на чёрном.
- Логотип основного развёрнутого хедера +25%; интенсивность изображения World Dots: 0.34 → 0.425 (+25% относительно прежней).
- Нативный TabView / Liquid Glass остаётся системным. Никаких дополнительных custom-tab-bars.
- Nuitee Hotels: сохранены Мекка/Медина, фильтр 1–5 звёзд, фотографии, цены по датам; объединённый разворачивающийся контейнер (графит #1C1C1E, 30pt), 1 ночь, 2 гостя, заезд через 10 дней.
- Flights: без смены провайдера или бизнес-логики поиска; одна графитовая раскрывающаяся форма маршрута, дат, пассажиров и кнопки поиска; найденные результаты остаются под формой, даже когда она свёрнута.
- Детали отеля: существующая Booking-like фотогалерея, по данным Nuitee условия отмены, конфиденциальность; добавлено расстояние по прямой до главной мечети при наличии проверяемых координат. Не является пешим маршрутом.
- Основные обозначения Care/Weekend/Account в RU, UZ (Latin/Cyrillic) приведены к языку вкладки; декоративные тематические иконки заменены на семантический монохром.
- Сохранена правка IumrahConnectivityMonitor, исправляющая потенциальную ошибку завершённой URLSession.

## Часть 2: Umrah Flow V2
Включены все 23 Swift-файла приложенного пользователем `iumrah-beta-update-20261026-umrah-flow-v2.zip`. Внутри Flow сохранены Orbit animation, swipe round confirmation, круговой прогресс, 7 обходов, аудиогид, автономные тексты и восстановление состояния. Внутренний `UmrahFlowHeader.swift` дополнительно оформлен в чёрном фирменном стиле и использует логотип и карту мира.

## Установка
1. Загрузить этот единственный ZIP в корень `kepler-ios`, применить штатным Apply Beta ZIP update.
2. Не загружать отдельно исходный Flow V2 одновременно, чтобы избежать гонки файлов.
3. Для iOS TestFlight использовать существующий Intel workflow; в ZIP нет `.github/workflows` и не меняются version/build numbers.
4. Настоящие тарифы Nuitee требуют `NUITEE_API_KEY` в том же Cloudflare Worker и активного Production API Key. Sandbox не является поставщиком коммерческих цен.

## Важно о проверках
Swift-синтаксис всех 279 Swift файлов разобран командой swiftc -frontend -parse. Серверные 138 контрактных тестов и 26 runtime-тестов прошли; TypeScript tsc --noEmit прошёл. Linux не содержит Apple iOS SDK/Xcode, поэтому полноценной Xcode-сборки, UI-тестов на iPhone и визуального контроля поведения новой сворачиваемой шапки здесь не было. Их нужно подтвердить на TestFlight перед релизом.

## Что это обновление не делает
Не подключает к расчёту умра-пакета коммерческие Nuitee-тарифы, не создаёт брони, не активирует Production-ключ и не меняет серверную маршрутизацию. Существующая логика Flight поиска/бронирования остаётся без изменений.
