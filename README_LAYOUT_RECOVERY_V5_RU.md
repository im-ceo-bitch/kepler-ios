# iumrah Layout Recovery V5 (30.10.2026)

Накопительный PATCH поверх Configurator + Unified Headers 2in1 BuildFix V3.

- Главная: убрать повторение трёх инструментов на белой панели; единственный переключатель в чёрном фирменном хедере, раскрытие молитв/погоды/создания умры в составе того же чёрного блока; убрать надпись «Главная» из раскрытой и компактной шапки.

- Конфигуратор: стадии Виза → Авиабилеты → Отели → Трансфер → Гид и поддержка → Итог. Визуальные варианты услуг сохраняются без оплаты и бронирования.

- Вкладка Hotels открывается каталогом, не авиабилетами; коллажи и поиск восстановлены путём возврата NuiteeHotelsCatalogView.swift к последней версии Hotels V4; на экране каталога не отображается накладывающаяся корзина.
- Все existing Umrah Flow, сервер Nuitee, Cloudflare, GitHub Workflows, номер билда, подпись и релизная версия не затронуты.

Проверено: Swift 6.2 frontend -parse всех 280 Swift-файлов, состав и целостность ZIP, поверх версии main+BuildFix V3. Полную Xcode-компиляцию и визуальные проверки на iPhone выполнить здесь нельзя. Это не подтверждённый к выпуску билд.
