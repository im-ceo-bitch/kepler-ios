IUMRAH — автоматическое исправление ошибки Repository preflight, 05.11.2026

Это корневой ZIP-патч для kepler-ios. Файлы в нём без вложенной папки:
  scripts/ci_preflight.py
  scripts/iumrah_preflight_repair_20261105.py
  scripts/iumrah_language_switch_compat_20261105.py

Где исправлено:
- scripts/ci_preflight.py, который уже запускается в TestFlight workflow,
  автоматически и явно вызывает два скрипта ДО Swift-парсинга и CI-аудита.
- первый скрипт добавляет 132 перевода в tuple switch и включает root RTL.
- второй добавляет недостающие языки в flat switch, сохраняя англоязычный
  текст как временный fallback. Исходные переводы RU/EN/UZ не удаляются.
- оставшиеся проверки CI прежние, ничего не обходится.

ВАЖНО: исправление запускается в checkout GitHub Actions, не коммитит
изменённые Swift-файлы обратно в репозиторий. Оно разблокирует дальнейшие
проверки в текущем CI, но не означает, что Xcode archive и TestFlight прошли.
Для постоянного исправления необходимо применить исправление на текущем main
и сохранить изменения в Swift-файлах. На ноябрьском main полная сборка Xcode
локально не выполнялась.

Осторожность: пакет использует предварительно проверенный текущий по
публичному GitHub scripts/ci_preflight.py, обновленный вызовами исправления.
Если в main после commit b018fa6... изменена preflight-логика, это обновление
может затереть такие изменения. Перед применением нужен актуальный SHA.
