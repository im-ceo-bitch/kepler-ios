# iumrah — единый накопительный UI-патч: 9 ноября 2026

## Что исправлено

1. Логотип расположен **строго по центру во всех пяти основных вкладках**, а не только на главной. Размер один: 187,2 × 57,6 pt. Общий компонент `IumrahPrimaryHeaderBrandRow` используется в главной и в четырёх остальных вкладках. Слева размещена нативная кнопка меню, справа — нативная кнопка уведомлений; это предотвращает столкновение с логотипом на небольших iPhone.
2. Заголовки **Отели, Бронирование, Поддержка, Аккаунт** увеличены с 22 до 28 pt и используют `IumrahType.bold` (Lato Bold при наличии шрифта). Динамический заголовок в карточке поиска главной увеличен с 18 до 22 pt.
3. Только **Главная** сохраняет нижние скругления чёрного хедера (30 pt). У четырёх остальных вкладок нижний край хедера прямой.
4. Устранено перекрытие поисковых карточек хедером: удалён передний `zIndex(1)` мастхеда, ранее скрывавший верх карточек Home и Hotels. Убрано ограничение компенсации overscroll 180 pt: сильный pull-to-refresh больше не должен сдвигать чёрный хедер вниз, открывая большой пустой участок над ним.
5. Поведение скролла не меняется: при свайпе вверх хедер уходит вверх, при pull-to-refresh вниз он не растягивается, а индикатор показывается под ним. Системные Liquid Glass API, 56-pt CTA, конфигуратор, Nuitee и iumrah Services сохранены.
6. В `DESIGN_RULES.md` согласованы правила логотипа, углов хедера и порядок отрисовки карточек. Добавлен контрактный тест.

## Установка

Это **самостоятельный накопительный ZIP относительно `kepler-ios-main 4.zip`**, включающий согласованные версии предыдущих обновлений и новый UI-fix. Установка промежуточных ZIP не нужна. Загрузите только этот файл в корень `main` без распаковки, затем запустите существующий `Apply iumrah Beta ZIP update`.

Важно: workflow распаковки обрабатывает **все** файлы `iumrah-beta-update-*.zip` в корне, поэтому удалите старые ожидающие ZIP, чтобы не перезаписать исправленные файлы. Данные/правки, внесённые в `main` вручную после исходного репозитория и не входящие в предоставленные патчи, могут быть затронуты.
