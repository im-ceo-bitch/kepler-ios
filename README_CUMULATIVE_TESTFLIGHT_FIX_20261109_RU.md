## Установка

1. Убедитесь, что в корне `main` **нет других** файлов `iumrah-beta-update-*.zip`, ожидающих распаковки. Workflow перебирает их в лексикографическом порядке; старые архивы могут перезаписать файлы.
2. Загрузите **этот один ZIP в корень репозитория** (не распаковывайте вручную).
3. Запустите существующий `Apply iumrah Beta ZIP update` и убедитесь, что коммит применился.
4. Запустите `TestFlight Upload` workflow. При необходимости примените серверные изменения штатным `deploy-package-engine` workflow (в архиве есть изменения Worker).
5. Если используется уже обновлённый репозиторий, этот ZIP повторно установит согласованные версии затронутых файлов; он не удаляет другие файлы репозитория.

**Ограничение:** актуальный live-HEAD GitHub после коммита из лога автоматически не проверялся. Патч проверен против предоставленной базы и всех доступных ZIP в чате. Если после этих ZIP вручную менялись те же файлы, они могут быть перезаписаны — перед установкой сравните изменения GitHub.
