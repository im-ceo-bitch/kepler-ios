# iumrah iOS · Native Liquid Glass + Nuitee Flight First

**Дата:** 08.11.2026  
**Применение:** ZIP-патч с путями от корня проекта. Его имя соответствует действующему `.github/workflows/apply-beta-update.yml`; новый workflow не требуется.

## Внесено

1. Кнопки меню, назад и уведомлений в новых хедерах — нативный SwiftUI `Button.buttonStyle(.glass)` для iOS 26+, системный `.bordered` для iOS 17–25. Нет подложенного серого круга, представляющего себя Liquid Glass.
2. Главные CTA — непрозрачные `Capsule`, 56 pt высоты, адаптируются по ширине. Добавлен обязательный `DESIGN_RULES.md`.
3. Логотип в хедере уменьшен примерно на 10%; убран вторичный текст под динамическим заголовком главной; сокращены вертикальные интервалы блока поиска; песочная рамка поиска заменена приглушённой зелёной.
4. Black hero корректно окрашивает верхнюю безопасную область, но скроллится со страницей; поисковая карточка перекрывает границу чёрного блока и светлого содержимого; карточка раскрывается касанием, без отдельного имитированного модального контрола.
5. Flight First: дата, число людей и класс вместо `2 + 0 + 0`, правка маршрута и дат внутри раскрываемой карточки, обновлённые карточки авиабилетов, нативный pull-to-refresh.
6. Новый путь `авиабилеты → отели Nuitee → трансфер → итог`; из публичной вкладки «Отели» удалено отображение старого каталога Business/D1. Исторические модели оставлены для сохранённых заявок и совместимости.
7. Отели в guided-поездке получают именно даты и число взрослых из выбранного маршрута. Эти параметры блокируются на экране выбора номера. Выбранная цена Nuitee в USD сохраняется вместе с `hotelId`, `offerId`, `roomId` и окнами проживания. Исправлена нормализация ключа «Медина» в хранилище выбранных отелей.
8. Локальная *предварительная* цена суммирует действительно выбранные тарифы авиаперелётов (за взрослого × взрослых), тарифы Nuitee (сумма за проживание), базовые услуги, наценку, 2% комиссии и дополнительные услуги по формуле `Backend/PackageEngine/src/pricing.ts`. Неизвестная цена остаётся `—`, а не нулём.
9. На этапах отелей, трансфера и итога работает `.refreshable` с проверкой выбранных Nuitee тарифов. Исчезнувший тариф удаляется из расчёта; подтверждённая серверная стоимость не симулируется.
10. Legacy-экраны `TransferSelectionView`/`FinalPackageView` также получили скроллящийся чёрный хедер и refresh. Новый путь не вызывает их старую серверную калькуляцию.

## Известные ограничения — принципиально не скрывать

- **Нет сертификата компиляции под Xcode.** На доступной Linux-машине успешно проверен парсером Swift синтаксис всех исходников, но iOS SDK отсутствует. Запуск `xcodegen generate`, полноценный `xcodebuild`, CI и визуальная проверка iPhone 11/13 mini остаются обязательными до TestFlight.
- Данные Data API — предварительные тарифы, а не забронированные места. Для опубликованных рейсов без числовой цены итог будет `—`. Не выдавать локальную оценку за готовое предложение с оплатой.
- **Nuitee v1 Worker** пока поддерживает один номер и взрослых без детских тарифов. Для детей/младенцев/нескольких номеров приложение не придумывает сумму и блокирует переход к неподтверждённой цене.
- Nuitee API-запросы по-прежнему проксируются через существующий PackageEngine Worker, чтобы секрет поставщика не попадал в приложение. Подключение боевых учётных данных и окончательная логика prebook/book должны быть сделаны на серверной стороне.
- Новый экран итога сознательно не предлагает оплату/оформление, пока не проверены flight ticketing, hotel prebook/book, сборы и договорное подтверждение. Старый механизм бронирований оставлен для действующих заявок.
- Новые экраны локализованы частично: русский текст преобладает в этапах Nuitee-сборки. Для полноценного релиза необходимо заполнить EN/UZ/UZ-Cyrl.

## Как применить

1. Загрузите `iumrah-beta-update-20261108-native-glass-nuitee.zip` **в корень** ветки `main` GitHub-репозитория iOS **как бинарный ZIP**, не распаковывая вручную.
2. Действующий workflow `Apply iumrah Beta ZIP update` извлечёт содержимое по относительным путям и удалит ZIP коммитом бота. Никаких новых workflow и токенов Cloudflare для этого патча не нужно.
3. Запустите штатный iOS TestFlight workflow. `project.yml` подключает `Sources` рекурсивно, поэтому новые `.swift` включатся при генерации Xcode-проекта.
4. Проверьте: iOS 26 glass, iOS 17 fallback, прокрутку/refresh, редактирование маршрута, JED/MED, обе даты, выбор разных отелей по городам, исчезнувшие тарифы, фактические USD на карточках, отсутствие старой базы на вкладке «Отели».
