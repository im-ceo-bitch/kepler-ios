# iumrah Design Evolution

Design source-of-truth for the iOS UI evolution. Stage 01 includes a source-code audit, visual foundations, and two comparison concepts.

- `DESIGN_RULES.md`: preliminary visual rules; typography Lato is not bundled/registered yet.
- `stage01/AUDIT.md`: limitations and review of the uploaded source baseline.
- `stage01/prototypes/index.html`: reference-only HTML prototype for concepts A and B; not an app runtime dependency.
- `stage01/prototypes/comparison.png`: side-by-side static comparison.

Production UI changes in this incremental patch: a more disciplined Home Hero treatment (variant A direction) and monochrome Home audience cards. All navigation/API/booking/auth/price functionality remains in place. The full A/B redesign remains a later decision.
