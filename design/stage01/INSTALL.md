# Как установить обновление

1. Загрузить `iumrah-beta-update-20261105-design-evolution-stage01-v1.zip` **в корень** ветки `main` репозитория. Не распаковывать вручную в GitHub.
2. Workflow `Apply iumrah Beta ZIP update` распознаёт имя `iumrah-beta-update-*.zip`, распаковывает пути относительно корня репозитория, удаляет ZIP и коммитит изменения.
3. Проверить Actions → `Apply iumrah Beta ZIP update` → зелёный результат и коммит с изменениями.
4. Отдельно запустить iOS Build-only CI, затем TestFlight, если предусмотрено. Распаковщик **не проверяет Swift сборку**.

Внутри ZIP нет верхней папки `kepler-ios-main`. Файлы под `Sources/` — полные версии (не diff), **будут перезаписаны**. Патч рассчитан на переданный пользователем архив `kepler-ios-main 3.zip`, не на неизученную версию удалённого GitHub `main`. Если `main` обновлялся после выгрузки этого ZIP, следует сначала сверить изменённые файлы, иначе возможно затирание новых изменений.

Не изменяются: `.github/workflows`, project.yml, сетевой слой, схема бронирований, конфигуратор, тарифы и бизнес-логика.
