# iumrah — объединённый патч: Nuitee Hotels V1 + заголовки + World of Dots

Дата: 26.10.2026. База: `kepler-ios-main 4.zip`.
Это ОДИН ZIP-патч. Два предыдущих патча по отдельности устанавливать НЕ нужно.
Все пути внутри архива относятся к КОРНЮ исходного репозитория.

## Что объединено

1. Новый чёрно-белый фирменный стиль основных вкладок, общие заголовки,
   нижняя навигация и анимированная карта мира (SwiftUI + Metal). Заголовок
   страницы отелей и три внутренних переключателя — на одном фоне.
2. Nuitee Hotels V1 В СУЩЕСТВУЮЩЕМ разделе «Отели»: Мекка/Медина, фильтр
   по звёздам 1–5, список отелей; стандартный заезд через 10 дней,
   1 ночь, 1 номер, 2 взрослых. Стоимость в карточке — за НОМЕР,
   не за весь умра-пакет.
3. Страница отеля: фото/галерея, описание, удобства, номера и тарифы
   по датам, индивидуальные условия отмены тарифа, где возвращает Nuitee.
4. Cloudflare Package Engine: серверные маршруты `/api/package/nuitee/*`,
   D1-кеш ориентировочных цен 48 часов и тарифов конкретного отеля 10 минут.
5. Старая гостиничная выдача из собственной базы отключена ТОЛЬКО во вкладке
   «Отели», но её код и данные оставлены для уже существующих сценариев.
   Авиабилеты и Sunday Club остаются на прежних источниках.

## Установка — ИСПРАВЛЕНО: без изменения GitHub Actions workflow

Причина ошибки предыдущего ZIP: `apply-beta-update.yml` пытался отправить изменение
`.github/workflows/deploy-package-engine.yml`, а у GitHub App не было разрешения
`workflows`. Этот исправленный ZIP НЕ содержит файлов `.github/workflows/`.

1. В корне GitHub-репозитория УДАЛИТЕ старый архив
   `iumrah-beta-update-nuitee-headers-world-dots-v1-unified.zip`, если он ещё
   есть. Иначе обработчик `apply-beta-update.yml` обнаружит и старый архив,
   повторно внесёт запрещённое изменение workflow и снова получит отказ.
2. Загрузите только ЭТОТ ZIP с именем
   `iumrah-beta-update-nuitee-headers-world-dots-v1-workflow-safe.zip`
   в КОРЕНЬ репозитория (не распаковывайте вручную).
3. GitHub Actions > `Apply iumrah Beta ZIP update`: дождитесь зелёного
   шага `Commit applied files`. Если ошибка сохранится, проверить, не остался
   ли старый ZIP и не было ли другого изменения в `.github/workflows/`.
4. В Cloudflare Workers & Pages > `iumrah-package-api` > Settings >
   Variables and Secrets должен быть секрет `NUITEE_API_KEY`.
   В GitHub его НЕ обязательно дублировать: обычное развертывание Wrangler
   использует сохранённый секрет существующего Worker.
5. GitHub Actions > `Deploy iumrah Package Engine` > Run workflow.
   Существующий workflow деплоит обновлённые исходники без изменения самого
   workflow. Таблица `nuitee_hotel_cache` создаётся idempotent D1 SQL
   при первом запросе `/api/package/nuitee/*` в коде
   `Backend/PackageEngine/src/nuitee-hotels.ts` (`ensure`).
   Файл миграции `0010_nuitee_hotel_cache.sql` дополнительно включён как
   история схемы; отдельно исполнять его необязательно для запуска V1.
6. Затем запускайте обычный iOS TestFlight workflow.

Нужны уже существующие GitHub Secrets для деплоя Cloudflare и старых интеграций,
которые проверяет текущий `Deploy iumrah Package Engine`. Новый секрет Nuitee
может жить ТОЛЬКО в Cloudflare Worker.

ВАЖНО: если старый ZIP уже попал в коммит GitHub, по логам он был извлечён,
но `git push` отклонён. Шаг `Remove ZIP files after failed apply` должен
очистить корень GitHub от ZIP. Убедитесь в этом до новой загрузки.

## Какие изменения вносятся

- 2 вкладки Мекка/Медина, фильтр 1–5 звёзд, карточки и подробные страницы,
  коллаж фотографий, тарифы и условия отмены из Nuitee.
- 48-часовой серверный кеш ориентировочных цен; на конкретном отеле — до 10 мин.
- Сохранён фирменный хедер с World Dots; остальные вкладки и старые источники
  авиабилетов не меняются.
- Существующие файлы `.github/workflows/` НЕ изменяются.

## Ограничения

- Текущий `sand_`-ключ возвращает ТЕСТОВЫЕ тарифы, не реальные цены.
- Выбор Nuitee-номера ещё не включён в окончательный серверный расчёт
  умра-пакета. Реальное бронирование в iumrah Business не сделано.
- Flights API Nuitee НЕ интегрирован: существующие Flights не изменены.
- Настоящая сборка Xcode/компиляция Metal, Cloudflare Deploy и реальные
  запросы Nuitee в рамках создания патча не выполнялись.
