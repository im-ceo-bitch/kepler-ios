# iumrah — Hotels UX V4 — ZIP patch

Состав: 5 существующих Swift-файлов. Не включает workflow, Cloudflare/Backend или версию приложения. Предназначен для установки ПОСЛЕ предыдущих накопительных исправлений, включая Hotels Nuitee и Umrah Flow V2.

Изменения:
- Закреплённый чёрный хедер на витрине Hotels/Flights/Weekend; при прокрутке сжимается, pull-to-refresh выполняется внутри светлой области под ним.
- Поле поиска по названию в Nuitee Hotels. Поиск локально среди полученных отелей без запроса поставщика на каждую букву. Совпадения и до 8 похожих альтернатив.
- Поисковый контейнер -> Мекка/Медина -> фильтр звёзд.
- Календарь выбора заезда и выезда в отдельном native sheet (от 1 до 28 ночей).
- Карточки: коллаж до трёх настоящих снимков; недостающие фото по мере появления карточки догружаются из cached hotel detail, максимум 3 одновременных запросов. Не придумываем изображения.
- Карточки номеров: карусель с точками, вместимость, удобства, питание, цена, условия отмены. Нажатие «Подробнее о номере» ведёт на отдельную страницу.
- «Добавить в план умры» записывает выбранное предложение в NuiteeStaySelectionStore. НЕ подключает финальный серверный расчёт пакета и НЕ бронирует отель.
- Убраны технические слова «тестовые тарифы» из клиентского каталога. Пока используется Sandbox, цену по-прежнему корректно помечаем как предварительную и явно пишем, что бронирование недоступно.
- Подпись Care локализована в главном экране поддержки и боковом меню; фирменное название «iumrah Care» в тексте продукта сохранено.
- Сегменты Бронирования приведены к той же форме белых/контурных pill-кнопок на чёрном фоне.

Важные границы проверки:
Проверен синтаксис всех доступных Swift-файлов и статическая структура патча. Полная Xcode-компиляция, реальная отрисовка на iPhone, коммерческое бронирование Nuitee и повторный деплой Cloudflare не выполнялись. После Apply обязательно TestFlight Intel.
