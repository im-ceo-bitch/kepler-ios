# iumrah · обновление V5 · 10 ноября 2026

Накопительный ZIP поверх предоставленного kepler-ios-main-5 и предыдущего V3. RU / EN / UZ Latin / UZ Cyrillic для новых элементов.

## Изменения
- Главная: поиск раскрыт при входе, удалён повтор заголовка и лишний нижний текст; основные CTA без декоративных иконок, текст по центру.
- «Что делать здесь?»: чёрно-серая анимация, печать текста, поддержка Reduce Motion и VoiceOver. В выборе рейсов и шагах конфигуратора — кнопка вопроса в хейдере и затемнённая подсказка. Автозакрытие через 2,5 секунды после печати; закрытие нажатием вне карточки. Для VoiceOver автозакрытие отключено.
- Удалены регистрации pull-to-refresh. Общие хейдеры прокручиваются вверх, но не растягиваются вниз: UIScrollView bounce отключён без компенсации offsets. Индикаторы загрузки данных сохранены.
- Кнопки хейдера используют штатный iOS 26 `.buttonStyle(.glass)` и круглую форму. На iOS 17–18 — штатный bordered fallback без имитации Liquid Glass.
- Календарь: доступны будущие даты в показанном диапазоне; опубликованные прямые рейсы выделены зелёным и объяснены легендой.
- Общая новая карточка авиабилета для каталога и конфигуратора. Метка Aviasales, фильтры прямых рейсов/авиакомпаний, сортировка по дате/цене/длительности, интерактивные минимальные цены по датам и выбор даты. График содержит только полученные тарифы. Багаж и оставшиеся места не выдумываются.
- Время прилёта передаётся через сервер и iOS-модель, когда поставщик его возвращает. Если его нет, при наличии длительности и известных часовых поясов показывается расчётное время с явной подписью. Расчёт не подменяет подтверждённый маршрут бронирования.
- Метка iumrah Direct на карточках отелей собственной базы; Nuitee-отелям она не присваивается.
- Удалена модель отложенного выбора Nuitee-отеля «уточнить цену». Ожидание API, отсутствие тарифа и ошибка различаются. Полученные цены показываются, включая честно помеченные sandbox-тарифы. В пакет добавляется выбранный номер с тарифом.
- Сохранены предыдущие исправления кеша каталога 150 отелей, фото, локализации и ожидания API без прежнего короткого прикладного таймера.

## Установка
1. Загрузить этот ZIP в корень репозитория. Имя соответствует `iumrah-beta-update-*.zip`, внутри пути относительно корня без дополнительной папки.
2. Дождаться распаковщика. Его успешный запуск только применяет файлы, он НЕ публикует приложение или backend.
3. Для iOS запустить `Iumrah | TestFlight | Intel | New Team` с актуальной ветки.
4. Серверные изменения требуют отдельного `Deploy iumrah Package Engine`. В текущем исходном репозитории есть пять ранее существовавших неуспешных контрактных тестов (ниже); стандартный npm test остановит deploy до их устранения. Эти проверки не отключены.
5. На iPhone 11/13 mini проверить светлую/тёмную тему, клавиатуру, длинные названия, VoiceOver, выбор обоих перелётов и загрузку цен. Старые ZIP не загружать повторно поверх V5.

## Проверки и ограничения
- TypeScript: `tsc --noEmit` проходит.
- Серверные runtime-тесты: 40/40, включая задержанный ответ Nuitee и сохранение/отсутствие arrivalAt.
- Контрактные тесты: 140/145. Те же пять ранее существовавших ошибок: carousel comparison; generator-production-pricing; app-selected widget locale; hardcoded booking labels; passwordless entry. Они не исправлялись в рамках UI-патча.
- Swift: синтаксический разбор всех изменённых файлов; это не компиляция с iOS SDK.
- Xcode, симулятор и TestFlight из этой среды не запускались. Плавность хейдера и компоновка требуют проверки собранного приложения.
- Live-проверка Nuitee для Мекки 23–30 ноября 2026, 2 взрослых: HTTP 200, 150 отелей, 85 с ценами, sandbox=true. Отдельный запрос номера без тарифа возвращал HTTP 502 NUITEЕ_PROVIDER_ERROR. Превышение лимита не подтверждено; этот внешний сбой и production-доступ поставщика нельзя исправить одной заменой UI. Необходимо проверить ответ поставщика после деплоя диагностического адаптера.
- Изменения подготовлены в исходниках. Ни сервер, ни приложение этим ZIP ещё не опубликованы.
