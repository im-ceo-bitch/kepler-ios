Обновление iUmrah — 9 ноября 2026, v2

Загрузите ZIP в корень репозитория: имя совместимо с apply-beta-update.yml.
Архив содержит накопительные изменения относительно присланного исходного ZIP.
После распаковки соберите iOS и разверните Backend/PackageEngine существующим workflow.

Изменения:
— Общий хедер выше на 20 pt; компенсация только вытягивания вниз; spinner под хедером.
— Вверх хедер уходит с контентом. Округление снизу только на Главной.
— Одинаковые круглые нативные glass-кнопки; нижний переключатель разделов над таббаром.
— Свёрнутый поиск с анимированной чёрно-белой рамкой, перекрытие границы хедера.
— Динамический заголовок раздела; город и направление под поиском.
— Начальный каталог опубликованных рейсов с завтрашнего дня и кешированных предложений.
— Карточки отелей с более округлыми углами и первыми тремя доступными фотографиями.
— Удалены служебные надписи и отдельная кнопка обновления.
— Отель без цены можно добавить на уточнение: он исключён из расчёта и передаётся поддержке.
— Перевод описаний и удобств с кешированием по языку.

Настройка переводов:
Без дополнительного ключа используется параметр language официального Nuitee API.
Для полного автоматического перевода, включая узбекский, задайте секрет Worker
HOTEL_TRANSLATION_API_KEY — ключ Google Cloud Translation API v2.
При недоступном переводе сохраняется исходный текст; перевод без ключа не гарантирован.
Тестовые цены sandbox не считаются реальными: отображается «Уточнить цену».
Для реальных цен нужен production-ключ Nuitee.

Уточнение отеля:
Выбор сохраняется отдельно от ценовых предложений, включается в заявку поддержки.
Автоматическое добавление неподтверждённой суммы отсутствует.
Новый механизм синхронизации цены после ручного подтверждения поддержки не добавлялся.
