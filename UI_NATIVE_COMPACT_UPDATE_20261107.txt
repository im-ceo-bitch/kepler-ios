ИЗМЕНЕНИЯ
- Системные segmented Picker вместо нарисованных капсул. На iOS 26 используется системный дизайн; на старых iOS — стандартный системный переключатель.
- Кнопки меню, уведомлений и возврата используют .buttonStyle(.glass) на iOS 26.
- Главная: компактная форма, динамический текст внутри, Desert Gold #B58645, радиус формы 30 -> 25.5 pt; нижние углы хедера 15 -> 30 pt; расстояние от логотипа до формы 32 pt.
- Аэропорт вылета без glass; даты и пассажиры — строки с разделителями.
- Для Мекка + Медина показывается первый аэропорт JED/MED, для Мекки — только JED.
- Одинаковые параметры presentation для календаря, пассажиров и аэропорта; единый inline-заголовок и закрытие справа.
- Класс перелёта в модалке пассажиров: один системный переключатель с четырьмя вариантами.
- Общий компактный хедер рейсов/отелей; светлая тема списка больше не получает чёрный фон. В тёмной теме фон хедера светлее контента.
- Рейсы точной даты идут первыми, затем отдельный раздел соседних дат; поиск минимум ±3 дня, без дубликатов, прошедших дат и несовместимых возвратов.
- После выбора пары рейсов открываются отели, затем существующий этап трансфера.
- Отели: сводка гостей/комнат/дат, системные переключатели города и звёзд; Медина показывается только для соответствующего маршрута. Постепенный показ по 20 карточек.
- Фото занимают 43% ширины вместо 31%; высота карточки 232 вместо 204 pt.
- Коллаж больше не дублирует обложку ради трёх ячеек; при нехватке фото показывает 1–2 реальных изображения. Фото пакетов дополняются из detail endpoint, URL вариантов размера дедуплицируются.

НЕЗАВЕРШЁННАЯ ИНТЕГРАЦИЯ
Nuitee в этой базе кода — отдельный каталог с room-only ценами и отдельными ID. Расчёт пакета использует HotelCatalogService и серверный каталог /api/catalog/hotels. В этом ZIP оформление каталога Nuitee исправлено, но он НЕ подключён вместо каталога пакета. Для этого необходима серверная интеграция выбранного Nuitee тарифа с датами по городам, размещением, rooms/children и расчётом пакета. Подмена его room-only цены полной ценой пакета не сделана.
