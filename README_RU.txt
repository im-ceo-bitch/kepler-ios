iumrah iOS — Header / Booking / Home Accordion V3, 27.10.2026

НАЗНАЧЕНИЕ
Этот ZIP — накопительный PATCH поверх установленного iumrah Black Identity + Umrah Flow V2 (2in1).
Он не заменяет весь репозиторий. Загружать ZIP в корень kepler-ios.
Имя соответствует триггеру GitHub Actions: iumrah-beta-update-*.zip.

СДЕЛАНО
1. Бронирование: Бронирование / Статус / Расписание перенесены внутрь одного чёрного хедера.
   При сворачивании они доступны под компактным чёрным заголовком.
   Даже без бронирования статус и расписание показывают собственные пустые состояния.
2. Аккаунт: подзаголовок физически перемещён внутрь чёрного хедера сразу под title.
3. Care: поясняющий подзаголовок внутри фирменного чёрного хедера.
4. Root header: title + subtitle без лишнего зазора; компактный header сохраняет
   интерактивные уведомления и меню, а не только статический логотип.
5. Главная: три квадратные карточки удалены; вместо них один белый блок
   Время молитв / Погода / Создать умру и один раскрываемый чёрный контент.
   Повторное нажатие сворачивает открытую секцию, нажатие другой — переключает.
6. Время молитв: используются существующие локальные методы расчёта iumrah,
   настройки и текущее местоположение после разрешения пользователя.
   Пока разрешения нет, отображается выбранный город с явным предупреждением.
7. Погода: текущие данные MET Norway по координатам пользователя с повторным
   использованием результата в течение 30 минут. При отказе/ошибке — сообщение,
   а не фиктивные данные.
8. Создать умру: запуск текущего iumrah конфигуратора, без дублирования логики.
9. UmrahHome: безопасный нижний отступ и тот же компактный фирменный header.
10. Существующие iOS Liquid Glass, Nuitee Hotels, Umrah Flow V2 и сетевой crash-hotfix не заменяются.

НЕ ВКЛЮЧЕНО
- Файлы .github/workflows (запрещены распаковщиком).
- Изменения App Store версии / build number.
- Новые API secrets или Cloudflare Worker code.
- Изменения бизнес-логики реального бронирования.
