# iumrah — Root Header Tabs V2

Накопительный PATCH поверх обновления `iumrah-beta-update-20261029-configurator-visual-flow-v1.zip` из `kepler-ios-main 4.zip`.

Что реализовано:
- Один общий SwiftUI-компонент `IumrahSignatureThreeTabs` во всех корневых вкладках: одинаковая геометрия, белая активная капсула, контур неактивных, accessibility labels.
- Главная: время молитв / погода / создать умру. Кнопки хедера раскрывают существующий рабочий инструмент и прокручивают к нему; кнопки в белом инструменте используют то же состояние. Сохранён индикатор соединения.
- Поддержка: связаться / услуги / вопросы. Кнопки прокручивают к действующим разделам.
- Бронирование: три действующих состояния через общий компонент.
- Аккаунт: профиль / поездки / настройки. При отсутствии аккаунта переход к авторизации вместо выдуманных поездок.
- Брендовый логотип увеличен с адаптивной шириной для узких iPhone и компактных хедеров. Уменьшен лишний верхний отступ.
- 4 этапа Конфигуратора (Авиабилеты / Отели / Услуги / Итог) сохранены, как было согласовано ранее. Увеличен логотип в панели Конфигуратора.
- При прокрутке используется существующая компактная чёрная закреплённая шапка и те же три переключателя.

Не изменялись: Nuitee/Cloudflare, бронирование, расчёты, API, Umrah Flow, `.github/workflows`, Apple подпись, номера сборок, системная нижняя Liquid Glass.

Проверено: синтаксический разбор 280 Swift-файлов (`swiftc -frontend -parse`), контрольные суммы, целостность архива.
Не проверено: Xcode compilation, архивирование, iPhone 11/13 mini QA. Успешный TestFlight нельзя гарантировать без macOS runner.
