# iumrah V22.1 — Signature Launch

Накопительный клиентский патч: включает V22 без потери предыдущих обновлений.

## Запуск
- Системный UILaunchScreen: статический почти чёрный фон в обеих темах. Анимация начинается после запуска SwiftUI, не внутри системного launch screen.
- На 0–0,2 с появляется белая точка с мягким импульсом; затем из неё формируется сфера.
- Географическая сфера: 5 195 офлайн-точек суши из существующей модели Natural Earth. Canvas группирует точки в шесть путей, TimelineView обновляет визуализацию до 30 кадров/с. Географическая проекция вращается с 81° до 48° долготы.
- Иллюстративный маршрут TAS → JED с SF Symbol airplane и световой волной. Это не реальное местоположение пользователя и не информация о забронированном рейсе.
- Два коротких импульса Core Haptics (0,08 и 0,82 с); подготовленный UIKit soft impact используется при недоступности движка. Без звука. При Reduce Motion — краткий переход с логотипом, без импульсов.
- В конце оригинальный белый HeaderWordmarkLight перемещается к геометрии существующего хедера, сфера переходит в фирменную плоскую карту. Для незавершённого онбординга — затемнение без перехода к отсутствующему хедеру.
- Продолжительность самой анимации 1,2 с по проектному таймингу, без ожидания сети. Реальное время холодного запуска зависит от производительности устройства и готовности RootView.
- RootView монтируется ближе к завершению (0,84 с), после основных визуальных кадров. Сцена не повторяется при foreground/resume. Прерывание уводит в приложение. Quick Actions и входящие URL обходят заставку; URL обрабатывается в RootView по уникальному идентификатору.

## Установка
Загрузить только `iumrah-beta-update-20261113-signature-launch-v22-1.zip` в kepler-ios. Распаковщик заменяет файлы по путям от корня. После распаковки запустить существующий TestFlight. Business V22, если ещё не применён, устанавливается отдельно по прежней инструкции; новая заставка серверных изменений не требует.
